# ZNU Survey Dashboard — داش بورد استطلاع رأي الطلاب

داش بورد لنتائج **استبيان تقييم أعضاء هيئة التدريس والهيئة المعاونة** في **جامعة الزقازيق الأهلية**، مقسمة حسب الكلية ← البرنامج ← المستوى.

🔗 **الداش بورد:** https://znu-survey-dashboard.vercel.app (ونسخة على GitHub Pages: https://ebrahimmehasen.github.io/znu-survey-dashboard/)
🧪 **معاينة ببيانات تجريبية:** https://znu-survey-dashboard.vercel.app/?demo

## فيها إيه
- نظرة عامة على الجامعة ومقارنة بين الكليات، وملخص لكل كلية ومقارنة بين برامجها
- لكل برنامج: فلتر بالمستوى، والرضا العام، وتقييم أعضاء هيئة التدريس والهيئة المعاونة
- ترتيب الدكاترة والمعيدين، والمقررات (في التجارة)، و20 بند تقييم، وملاحظات الطلاب مع بحث
- صفحة تفاصيل لكل عضو: البنود، وتوزيع الإجابات، والتقييم حسب المقرر أو المستوى، والملاحظات

## مصدر البيانات
الردود بتتسحب من شيت "ZNU Survey Dashboard - Public data (no emails)" على حساب صاحب الداش بورد. فيه تاب لكل فورم بيستورد الردود بـ IMPORTRANGE من غير عمود الإيميل، والشيت منشور (Publish to web) كـ CSV. شيتات الردود الأصلية نفسها فاضلة خاصة.

## ربط فورم جديد
1. افتح الفورم ← **Responses** ← **Link to Sheets**.
2. في الشيت: **Share ← General access ← Anyone with the link (Viewer)**.
3. انسخ لينك الشيت وحطه في `sheetUrl` للفورم ده في [`assets/js/config.js`](assets/js/config.js).

## إضافة فورم جديد أو تعديل فورم
1. ضيف الفورم في `forms` جوه `assets/js/config.js`.
2. شغّل `node tools/build-schema.js` عشان يتحدث `data/forms.json` (أسماء الدكاترة والمعيدين والبنود).
3. اعمل commit و push.

## الصور
- `assets/img/campus-bg.webp` و `campus-bg-sm.webp`: صورة الجامعة (نفس صورة بوابة الأنشطة)
- `assets/img/logo.webp`: لوجو الجامعة

## تشغيل محلي
```bash
node .claude/serve.js
```
بعدها افتح http://localhost:5500 (أو http://localhost:5500/?demo للبيانات التجريبية).
