# ZNU Survey Dashboard — داش بورد استطلاع رأي الطلاب

داش بورد لنتائج استطلاع رأي الطلاب في **جامعة الزقازيق الأهلية**، مقسمة حسب الكلية والبرنامج، وفيها إحصائيات الدكاترة والمعيدين والمواد والأسئلة العامة وآراء الطلاب.

## الكليات والبرامج
| الكلية | البرامج |
|---|---|
| الهندسة | الميكاترونكس، التشييد |
| طب الأسنان | طب وجراحة الفم والأسنان |
| الصيدلة | الصيدلة |
| التجارة | المحاسبة، إدارة الأعمال |
| الحاسبات والمعلومات | نظم معلومات الطيران، المعلوماتية الطبية، الذكاء الاصطناعي |

## ربط فورم ببرنامج
1. افتح شيت الردود بتاع الفورم (Google Forms ← Responses ← Link to Sheets).
2. اعمل الشيت **Share ← Anyone with the link (Viewer)** أو **File ← Share ← Publish to web ← CSV**.
3. حط اللينك في `sheetUrl` للبرنامج في [`assets/js/config.js`](assets/js/config.js).

الداش بورد بتقرا الردود مباشرة وبتتحدث تلقائيًا كل 5 دقايق.

## الصور
- `assets/img/background.jpg` — خلفية الجامعة
- `assets/img/logo.png` — لوجو الجامعة

## التشغيل
- معاينة ببيانات تجريبية: افتح `index.html?demo=1`
- تشغيل محلي: `node .claude/serve.js` ثم افتح http://localhost:5500
